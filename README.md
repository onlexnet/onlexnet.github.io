# OnLex.net

Plain static one-page website (HTML/CSS/JS, no build step).

1. Use it as a devcontainer.
2. Preview locally: `npx serve .` (or any static file server), then open `http://localhost:3000`.
3. Deployed automatically to GitHub Pages via [.github/workflows/deploy-pages.yml](.github/workflows/deploy-pages.yml) on every push to `main`.
